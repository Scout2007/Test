# Agent 05 · Tally

**Goal.** Combine one round's five reviews into a ranking, and say what each variant does best.

**Read** the round's five files `trailer/work/reviews/r<N>_<lens>.md`.

**Write** `trailer/work/reviews/r<N>_tally.md`:
- **Score table:** variants × lenses, plus totals and the rank.
- **Majors** per variant, de-duplicated across lenses, each with its lens.
- **Best parts** per variant, collected from every reviewer, with the shot numbers.
- **Agreement and disagreement.** Where reviewers disagree, quote both sides in one line each.
- **Recommendation.** Which variants to revise and which, if any, to drop. Drop only a variant below half the top total.

**Rules.** Report; don't judge anew.

**Reply** in at most 5 lines: the ranking with totals, and the drop recommendation.
